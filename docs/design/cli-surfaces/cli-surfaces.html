Design · ARP v0 surfaces · from the spec "hook d'usage et arp status" Tool names real · every figure sample

When a tool fails, is it you or everyone?

Three surfaces answer it. The terminal, where the developer looks. The badge, which shows it. The public page the badge opens, where every figure can be checked.

01

Terminal

Mono, left aligned, no box drawing. Colour carries state only: red for a tool broken for you or everyone, paper for a fact, grey for what is not known yet. The alerts come first, before the table, because they are why someone runs the command.

Badges

Two segments, like every README badge, so it sits in a row of them. The left one is the mark: graphite, the Saffron core, ARP. The right one is the fact, computed from public data only. No colour for good or bad: a badge that turned red would be a score.
