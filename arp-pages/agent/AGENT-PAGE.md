**For:** Claude Code. **Route:** `/agent/:chainId/:tokenId` (`AgentTrustPanel`). **Brief:** `docs/16_THE_AGENT_PAGE.md`, whose order this follows. **Reference:** `agent-page.html`, with three cases: used by 7, nobody yet, no metadata.

Real in the reference: the tool atoms it declares (`catalogue/tools.json`). **Everything else is a sample**: the agent, parties, positions, curves, endpoints, assessment, ids. Never ship them.

## 2. Rules

- One Saffron action on the page: **Declare you used it**. Back it is secondary, because it is attention, not the product.
- Never a score. Never sum across vaults: the two counts in "Who used it" are **people**, not money.
- Every figure says which chain it comes from (the mainnet and testnet switch).
- "Not reported" and "none" are different sentences.
- The claim field is the one from `claim-field-port`, with the ring names on the field.

## 3. Done means

- The three cases render. No metadata: generated name in mono, no sigil when nothing is declared, every empty state in words.
- `check:tokens`, `tsc -b`, `lint`, `test` pass. 390px: no horizontal scroll, the sigil stacks above the name.
