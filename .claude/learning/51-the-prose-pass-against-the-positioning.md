## Surprises

- **A prose pass is a facts pass.** The README carried two sentences the ADRs contradict — "pay-per-use
  is out of scope" (ADR `0112`) and "there is no proof-of-usage layer, and there is not going to be
  one" (ADR `0094`'s _proven_ label). `docs/15` listed `ModuleRegistry` and `DomainScopeEnforcer` as
  deployed and gating on testnet, two weeks after `59ac83a` deleted both. Same finding as the
  2026-10-27 pass, which took six factual errors out of the same README.
- **The canonical doc contradicted the product.** `docs/12` said "not consumer-facing", while the
  Desktop extension is built for people who never open a terminal and the kit names them first. Only
  reading the business repo beside this one surfaced it; neither repo alone shows the contradiction.
- **The second source of authority is the stalest file read.** `CLAUDE.md` ranks `docs/02` second
  and calls it "locked decisions"; its components, SDK shape and integration sections describe a
  contract deleted on 2026-10-21 and a feedback path ADR `0048` rejected. Only the storage principle
  still holds.
- **Most recent docs needed nothing.** `docs/21`–`26`, written after 2026-10-29, were aligned. The
  drift is in what was written before the discovery product existed.

## Decisions made

- **Annotate dated docs, do not rewrite them.** `docs/09`, `13`, `15`, `02` get a "here → now" table
  in the header and keep their body. A rewrite would erase the record of why a choice was made; a
  header stops a reader acting on it.
- **ARP is not B2B first.** The user's decision. ADR `0120`.
- **Prettier only where the file was clean before.** `docs/00` was reformatted by accident and
  reverted to the one-line change; `docs/12`, `14`, `23`, `25` and `.claude/STATE.md` already failed
  `prettier --check` and were left unformatted rather than drowned in noise.
- **Generated and external files reported, not edited.** The plugin description in `packaging/`
  (generated by `apps/cli`) and the deck cover in `ARP-business-dev` both contradict the kit; both
  are listed in `docs/tasks/27`.
